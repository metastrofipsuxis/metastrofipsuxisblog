Όταν μιλάω για την ανάγκη να είσαι αρκετός, έχω δει μέσα μου το πλάσμα που πάλευε να αποδείξει ότι αξίζει.

Όταν μιλάω για έλεγχο, έχω γνωρίσει τον δικό μου έλεγχο.

Όταν μιλάω για εξάρτηση, έχω κοιτάξει τις δικές μου εξαρτήσεις.

Όταν μιλάω για ντροπή, δεν την παρατηρώ από ασφαλή απόσταση.
Έχω καθίσει μαζί της.

Όταν μιλάω για το παιδί που έμαθε να κρατά τους άλλους όρθιους, ξέρω πολύ καλά αυτό το παιδί.

Κι όταν μιλάω για την ανάγκη να αφήσεις κάποτε κάτω αυτό που δεν σου ανήκει, δεν σου ζητώ να πας σε έναν τόπο στον οποίο εγώ αρνήθηκα να μπω.

Αυτό δεν σημαίνει ότι έχω λύσει τα πάντα.
Δεν θέλω να δημιουργήσω αυτή την ψευδαίσθηση.

Θεωρώ εξαιρετικά ύποπτο έναν άνθρωπο που δηλώνει τελειωμένος.

Η ζωή συνεχίζει να αποκαλύπτει.
Συνεχίζει να αφαιρεί.
Συνεχίζει να σε βρίσκει στα σημεία όπου νόμιζες ότι είχες ήδη καταλάβει.

Κι εγώ συνεχίζω να κοιτάζω.
Να παρατηρώ.
Να διαβάζω.
Να γράφω.
Να πέφτω πάνω στα δικά μου τυφλά σημεία.
Να βλέπω πού εξακολουθώ να αμύνομαι.
Πού εξακολουθώ να θέλω να έχω δίκιο.
Πού ο φόβος ντύνεται λογική.
Πού η παλιά πληγή προσπαθεί να παρουσιαστεί ως σοφία.

Δεν θεωρώ ότι ο θεραπευτής βρίσκεται έξω από την ανθρώπινη κατάσταση.
Αντίθετα.

Θεωρώ ότι ο άνθρωπος που κάθεται απέναντί σου οφείλει να έχει κατέβει όσο βαθύτερα μπορεί μέσα στη δική του.

Γιατί διαφορετικά υπάρχει ο κίνδυνος να προσπαθήσει να σε οδηγήσει σε μέρη που ο ίδιος φοβάται.

Κι εγώ δεν θέλω να σου λέω από την ακτή πώς είναι ο ωκεανός.
Θέλω, όσο μπορώ, να έχω βραχεί.

Γι’ αυτό δεν μπορώ πραγματικά να ξεχωρίσω την προσωπική μου διαδρομή από αυτό που κάνω σήμερα.

Δεν έγινα θεραπευτής παρά τη ζωή μου.
Έγινα μέσα από αυτήν.

Μέσα από όσα χρειάστηκε να καταλάβω.
Μέσα από όσα χρειάστηκε να ξεμάθω.
Μέσα από τις φορές που μπέρδεψα την αγάπη με την ευθύνη.
Τη δύναμη με το να μη χρειάζομαι κανέναν.
Την ωριμότητα με το να αντέχω τα πάντα.
Την πνευματικότητα με το να υπερβαίνω αυτό που στην πραγματικότητα χρειαζόταν να αισθανθώ.

Και ίσως γι’ αυτό, όταν κάθεσαι απέναντί μου, δεν θέλω να σε κοιτάξω σαν περίπτωση.

Θέλω να θυμάμαι ότι πίσω από κάθε «σύμπτωμα» υπάρχει ένας άνθρωπος που κάποτε προσπάθησε με τον καλύτερο τρόπο που γνώριζε να προστατεύσει τη ζωή του.

Θέλω να ψάξουμε μαζί όχι μόνο τι σου συμβαίνει,
αλλά πώς έμαθες να γίνεσαι αυτός που είσαι για να μπορέσεις να επιβιώσεις μέσα σε όσα σου συνέβησαν.

Και ύστερα να δούμε το δυσκολότερο:

αν αυτό που κάποτε σε έσωσε
είναι σήμερα αυτό που σε φυλακίζει.

Δεν σου υπόσχομαι ότι θα έχω πάντοτε απάντηση.

Σου υπόσχομαι όμως κάτι που για μένα είναι πολύ πιο σοβαρό:
ότι δεν θα προσποιηθώ πως έχω.

Δεν θέλω να είμαι ένας άνθρωπος που σου πουλά βεβαιότητα.

Θέλω να μπορώ να σταθώ μαζί σου ακόμη και μπροστά στο άγνωστο.

Να σου πω «δεν ξέρω» όταν δεν ξέρω.
Να σε αμφισβητήσω όταν βλέπω ότι ένα ψέμα σε προστατεύει.
Να αμφισβητήσω και εμένα όταν βλέπω ότι η δική μου γνώση μπαίνει ανάμεσα σε εμένα και σε εσένα.

Γιατί τελικά, πίσω από όλα τα βιβλία, πίσω από τις θεωρίες, πίσω από τις λέξεις «θεραπεία», «αυτογνωσία», «πνευματικότητα», υπάρχει κάτι τρομερά απλό:

ένας άνθρωπος απέναντι από έναν άνθρωπο.

Και ίσως η βαθύτερη θεραπεία αρχίζει ακριβώς εκεί.

Όταν για πρώτη φορά δεν χρειάζεται να αποδείξεις τίποτα.
Δεν χρειάζεται να γίνεις κάτι.
Δεν χρειάζεται να με εντυπωσιάσεις.
Δεν χρειάζεται να κρύψεις αυτό για το οποίο ντρέπεσαι.
Δεν χρειάζεται καν να ξέρεις τι ψάχνεις.

Αρκεί να είσαι πρόθυμος να κοιτάξεις.

Κι εγώ θα είμαι εκεί,
όχι για να ζήσω τη ζωή σου αντί για εσένα,
αλλά για να κρατήσω μαζί σου το φως
όσο εσύ αρχίζεις να βλέπεις
εκείνα που για χρόνια
χρειάστηκε να ζεις στο σκοτάδι.
